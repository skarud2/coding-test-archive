# 업그레이드 된 아이템 구하기

[문제](https://school.programmers.co.kr/learn/courses/30/lessons/273711)

RARE 아이템에서 바로 다음으로 업그레이드할 수 있는 아이템의 ID, 이름, 희귀도 조회
아이템 ID 내림차순 정렬

## 테이블

- ITEM_INFO: 아이템 ID, 이름, 희귀도, 가격
- ITEM_TREE: ITEM_ID는 현재 아이템, PARENT_ITEM_ID는 업그레이드 전 아이템

예를 들어 ITEM_ID = 1, PARENT_ITEM_ID = 0이면 0 → 1 관계

## 몰랐던 점

- 다음 아이템을 찾으려면 정보 테이블의 ITEM_ID와 관계 테이블의 PARENT_ITEM_ID를 연결
- IN 안에 서브쿼리로 조회한 ID 목록을 넣을 수 있음
- 콤마 조인보다 JOIN ON으로 연결 조건을 따로 적으면 읽기 편함

## 풀이

1. RARE 아이템의 ID와 그걸 부모로 가진 관계를 연결
2. 그 관계에서 다음 아이템의 ID인 t.ITEM_ID 조회
3. 바깥 쿼리에서 해당 ID의 이름과 희귀도 조회

```sql
SELECT ITEM_ID, ITEM_NAME, RARITY
FROM ITEM_INFO
WHERE ITEM_ID IN (
    SELECT t.ITEM_ID
    FROM ITEM_INFO i
    JOIN ITEM_TREE t
        ON i.ITEM_ID = t.PARENT_ITEM_ID
    WHERE i.RARITY = 'RARE'
)
ORDER BY ITEM_ID DESC;
```

## 헷갈리지 말기

RARE여야 하는 건 업그레이드 전 아이템
다음 아이템은 다른 희귀도여도 되므로 바깥 쿼리에 RARE 조건을 걸면 안 됨
문제 예시의 ITEM_C도 LEGEND지만 RARE인 ITEM_A의 다음 아이템이라 포함됨

직속 다음 아이템을 찾는 거라 여러 단계를 한 번에 따라가지는 않음
