# 시뮬레이션 / 반복 종료 조건

주어진 규칙을 적용하면서 상태를 갱신
먼저 언제 끝내야 하는지 확인하고 반복문 작성

## 변화가 없을 때까지 반복

변경 전 상태와 변경 후 상태를 비교
같은 상태에 같은 규칙을 적용하는 경우, 둘이 같으면 이후에도 변하지 않음

```python
count = 0

while True:
    before = data.copy()  # 숫자만 들어 있는 리스트 기준

    # 여기에 data를 바꾸는 규칙 적용

    if before == data:
        break

    count += 1
```

위 코드는 실제로 상태가 바뀐 횟수를 셈
마지막으로 같아졌는지 확인한 반복까지 세는지는 문제 조건에 따라 다름

## 리스트 복사 주의

```python
before = data         # 같은 리스트를 가리킴. 복사 아님
before = data.copy()  # 바깥 리스트를 새로 만듦 (얕은 복사)
```

data의 원소를 직접 바꾸면 before = data로는 이전 상태를 보관할 수 없음
다만 data에 새 리스트를 대입하는 경우에는 기존 리스트까지 바뀌는 건 아님

중첩 리스트는 copy()를 해도 내부 리스트를 공유
내부까지 직접 수정한다면 deepcopy 같은 별도 복사가 필요
새로운 after 리스트를 만들어 비교하는 방식도 가능

## 목표 값에 도달할 때까지 반복

```python
count = 0

while num != target:
    # 여기에 num을 바꾸는 규칙 적용
    count += 1
```

목표 값이 정해져 있으면 이전 상태와 비교할 필요 없이 목표에 도달했는지 확인
처음부터 목표 값이면 반복 횟수는 0

## 반복이 끝난다는 보장이 있는지

이전 상태와 다르다고 언젠가 멈추는 건 아님
A → B → A처럼 순환할 수도 있음

최대 횟수가 주어지면 그 제한을 지키고, 순환 감지가 필요하면 방문 상태를 기록
문제에 없는 횟수 제한을 임의로 넣으면 정상적인 답을 놓칠 수 있음
