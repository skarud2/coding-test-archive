# 문자열

## 슬라이싱

문자열에서 원하는 구간만 가져오기
s[시작:끝] 형태로 사용. 시작은 포함, 끝은 포함 안 됨
시작을 생략하면 처음부터, 끝을 생략하면 마지막까지
음수 인덱스는 뒤에서부터 셈. -1이 마지막 문자

```python
s = "01012345678"

print(s[:3])   # 010
print(s[-4:])  # 5678: 뒤 4자리
print(s[:-4])  # 0101234: 뒤 4자리 제외
```

s[:len(s) - 4]와 s[:-4]는 길이가 4 이상인 문자열에서 같은 의미
슬라이싱해도 원래 문자열은 바뀌지 않음

## 문자열 반복 (*)

문자열에 정수를 곱하면 그 횟수만큼 반복

```python
print("*" * 3)  # ***
print("ab" * 2)  # abab
```

## 예시: 전화번호 뒤 4자리만 남기기

전화번호 길이가 4 이상인 경우

```python
phone_number = "01012345678"

result = "*" * len(phone_number[:-4]) + phone_number[-4:]
print(result)  # *******5678
```

앞부분 길이만큼 *를 만들고, 뒤 4자리를 +로 이어 붙이기
길이를 직접 계산하면 "*" * (len(phone_number) - 4)로도 쓸 수 있음

## 문자열과 숫자 연결

문자열과 숫자는 +로 바로 더할 수 없음

```python
position = 1

# "위치: " + position  # TypeError
print("위치: " + str(position))  # 위치: 1
```

str()로 숫자를 문자열로 바꾼 다음 연결

## f-string

문자열 앞에 f를 붙이고, 중괄호 안에 변수나 식을 넣기
숫자를 따로 str()로 바꾸지 않아도 됨

```python
position = 1

print(f"위치: {position}")  # 위치: 1
print(f"{position + 1}번째")  # 2번째
```

중괄호 안의 식은 계산한 결과가 들어감
인덱스는 0부터 시작하므로 몇 번째인지 표현하려면 1을 더하면 됨
