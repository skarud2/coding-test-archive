# 콜라츠 추측

[문제](https://school.programmers.co.kr/learn/courses/30/lessons/12943)

짝수면 2로 나누고, 홀수면 3을 곱하고 1을 더하기
1이 될 때까지 작업한 횟수 반환
처음부터 1이면 0, 500번 작업해도 1이 아니면 -1

## 정리할 점

이전 값과 같아지는지 비교하는 문제가 아니라 목표 값 1에 도달했는지 확인하는 문제
매번 나온 값에 다시 규칙을 적용

## 내가 푼 코드

```python
def solution(num):
    if num==1:
        return 0
    count=0
    result=0
    bf_num=num
    while(result!=1):
        result=(bf_num//2) if (bf_num%2==0) else (bf_num*3+1)
        count+=1
        bf_num=result
        if count>500:
            return -1

    return count
```

bf_num은 이번 계산에 쓸 값, result는 계산한 결과
bf_num = result로 다음 반복에 쓸 값을 갱신
이전 값과 비교하는 게 아니라 result가 1이 될 때까지 반복하는 구조

## 다시 볼 점

count > 500은 501번째 계산까지 한 다음 -1을 반환
반환값은 맞지만 500번 안에서 끝내려면 반복 조건에 제한을 넣는 게 더 명확함

```python
while result != 1 and count < 500:
    result = bf_num // 2 if bf_num % 2 == 0 else bf_num * 3 + 1
    count += 1
    bf_num = result

return count if result == 1 else -1
```

위 부분만 바꾸고 처음 num == 1이면 0을 반환하는 코드는 유지
count >= 500에서 무조건 -1을 반환하면 정확히 500번째에 1이 된 경우를 놓칠 수 있음

## 주의

- 나눌 때 //를 써서 정수 유지
- 횟수는 규칙을 한 번 적용한 뒤 증가
- 500번째 작업으로 1이 됐으면 500 반환. 마지막 상태까지 확인
- 500번 제한은 이 문제의 조건. 모든 반복 문제에 같은 제한을 쓰는 건 아님

## 확인

- 1 → 0
- 6 → 8
- 16 → 4
- 626331 → -1
